# Changelog

## 0.9.0 — complete first working release

- Declarative YAML recipes and automatically generated quick-plot commands.
- Twenty-eight separated plot modules across Cartesian, categorical,
  distribution, 2D-field, 3D, and annotation families.
- Single, stacked, grid, and mosaic layouts with square physical panel cells.
- Shared left axes, right-hand y axes, legends, colorbars, scales, and ticks.
- CSV, TSV, whitespace, JSON, Excel, Parquet, and Feather inputs.
- Recorded filters, transformations, interpolation, and smoothing.
- Draft PDF workflow and optional `--final` recipe/lock provenance bundle.
- Indigo-led colour theme without Matplotlib's conspicuous default blue.
