# Source references

These are reference copies of the older `consol` LOBSTER generator scripts, with CAT naming applied. They are excluded from the installed packages. `lobsterin_create.py` references the old external `lobster_topology` module; the `(1)` file was a compatibility wrapper.

Use `cat-prepare lobsterin` and `cat_prepare.lobsterin.generate_lobsterin` instead. The active shared topology is `cat_shared.bonding.topology`.
