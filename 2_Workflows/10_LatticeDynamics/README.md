# Lattice Dynamics

Start with [baseline harmonic workflows](01_Harmonic/README.md): finite-displacement
VASP/Phonopy and DFPT. These build on [Common](../00_Common/README.md).

With completed harmonic force data, follow the
[FreqBall workflow](01_Harmonic/02_DirectionalDOS/README.md) for local direction
families, directional spectra, 3D frequency balls, conduction fatbands and parallel
artificial-mass scans. It contains the execution sequence, editable configuration,
plot recipe and scheduler template. The separate
[FreqBall reference](../../3_Analysis/docs/freqball.md) defines settings and outputs.
