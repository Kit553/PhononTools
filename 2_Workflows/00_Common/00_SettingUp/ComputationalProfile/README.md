# Onboarding new Computational Profiles

**Prerequisits** A configured university VPN and membership of the q0Zeier group or another cluster eligible group (HIMS, etc).

**Use:** Set up connection to PALMA-II, set up Python with package management and VS Code as the dedicated IDE, install the groups computational packages, and work with a CLI.

## Conventions

Placeholders are typed in `SCREAMING_SNAKE_CASE`.

`$HOME`: Your local or PALMA-II home directory; keep scripts you frequent here.

`WORK`: Wherever your data goes.

**Where do code go?** `PS>` means the command should be run in Windows Powershell; `cmd>` refers to **Windows** command line; `$` denotes Bash commands on PALMA-II or; a local bash installation e.g. through a WSL.

## 1. Get registered as a PALMA-II User

Login through the universities IT portal then navigate to `University ID (account) and group memberships`>`Group Memberships`>`Request, extend, show` then select the group u0clstr and request access. Do this at least 1 day before you want to actually work on PALMA-II as the membership needs to roll over once.
A short message to the admins is nice but the request generally gets accepted very quickly.
