# Setting Up

Prepare the structure, potential library, software environment and scheduler inputs
before starting convergence tests.

- [VASP setup](VASP/README.md): structure sources/conversion, POTCAR generation,
  INCAR choices, k-point meshes, execution layout and output inspection.
- [Benchmarking](VASP/benchmarking.md): compare small, medium and large systems.
  Keeping a [shared benchmark log](VASP/benchmark-log.md) accessible to everyone
  in the group is strongly recommended so colleagues can improve settings together.

Continue with [convergence](../01_Convergence/README.md) once a small trial runs successfully. See the [common index](../README.md) for the complete handoff sequence.
