# Setting Up

**Use:** Prepare inputs and an execution environment before starting convergence tests.

**Files:** [VASP input examples](VASP/) · [benchmark log](VASP/benchmark-log.md).

Prepare the structure, potential library, software environment and scheduler inputs before starting convergence tests. Use your local launcher or scheduler.

- [VASP setup](VASP/README.md): structure sources/conversion, `POTCAR` generation, `INCAR` choices, k-point meshes, execution layout and output inspection.
- [Benchmarking](VASP/benchmarking.md): measure representative workloads on your hardware. Keep a personal or shared [benchmark log](VASP/benchmark-log.md) so the measurements remain attributable and reusable.

Continue with [convergence](../01_Convergence/README.md) once a small trial runs successfully. See the [common index](../README.md) for the complete handoff sequence.
